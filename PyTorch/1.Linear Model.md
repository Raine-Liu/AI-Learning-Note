#### Model design
What would be the best model for the data?
先选Linear Model：y = x\*w+b
简化：y(hat)=x\*w
- w=?:The machine starts with a random guess, w = random value，计算预测值与真实值的差值
	Training Loss(Error) :$loss = (\hat y - y)^2 = (x*w - y)^2$
	找权重使平均损失（loss/个数）尽量低
	Mean Square Error（MSE 平均平方误差）：$cost=\frac{1}{N}\sum\limits_{i=1}^N (\hat y_n - y_n)^2$
		穷举法：绘制cost-w曲线，找最小值
```python
import numpy as np
import matplotlib.pyplot as plt

x_data = [1.0, 2.0, 3.0]
y_data = [2.0, 4.0, 6.0]

def forward(x):
	return x*w #前馈模型

def loss(x, y):
	y_pred = forward(x)
	return (y_pred - y) * (y_pred - y) #损失函数

w_list = []
mse_list =[] #准备空列表保存w和对应损失值
for w in np.arange(0.0, 4.1, 0.1) #采样——间隔0.1的序列
	print("w=",w)
	l_sum = 0
	for x_val, y_val in zip(x_data, y_data):#用这两组数据拼成所需数据
		y_pred_val = forward(x_val)
		loss_val = loss(x_val, y_val)
		l_sum += loss_val #求和
	print('\t',x_val, y_val, y_pred_val, loss_val)
	w_list.append(w)
	mse_list.append(l_sum/3) #打印+均值
	
#绘图
plt.plot(w_list,mse_list)
plt.ylabel('Loss')
plt.xlabel('w')
plt.show
```
以后根据Loss-epoch曲线决定训练轮数，避免发散（欠拟合——过拟合）
