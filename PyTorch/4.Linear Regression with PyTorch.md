#### Prepare dataset
mini-batch:
$$\begin{aligned}
\hat y_1 = \omega \times x_{1} + b\\
\hat y_2 = \omega \times x_{2} + b\\
\hat y_2 = \omega \times x_{2} + b\\
\end{aligned}
$$
广播机制，$\omega,b$自动扩展,对应位置相乘
$$\begin{bmatrix}\hat y_1 \\\hat y_2 \\\hat y_3 \\ \end{bmatrix}=
\begin{bmatrix} \omega \\ \omega \\ \omega \\ \end{bmatrix} · \begin{bmatrix} x_1 \\x_2 \\x_3 \\ \end{bmatrix} + \begin{bmatrix} b\\ b\\ b \end{bmatrix}
$$
$$
\begin{bmatrix}loss_1 \\loss_2 \\loss_3 \\ \end{bmatrix} = (\begin{bmatrix}\hat y_1 \\\hat y_2 \\\hat y_3 \\ \end{bmatrix} - \begin{bmatrix} y_1 \\ y_2 \\ y_3 \\ \end{bmatrix})^2
$$
```python
import torch

x_data = torch.Tensor([[1.0], [2.0], [3.0]])
y_data = torch.Tensor([[2.0], [4.0], [6.0]]) #x,y的值为矩阵
```

#### Design Model
PyTorch 中的重点：构造计算图
Linear Unit : 乘权重加偏置
	需要知道x, $\hat y$的形状来确定权重的形状
$x, \hat y$ 可为任意形状矩阵，但loss只能为标量（0维张量），故 $loss=\sum loss_i$

```python
class LinearModel (torch.nn.Module):# inherit from nn.Module
	def __init__(self): #构造函数
		super (LinearModel, self).__init__() #super调用父类的构造函数
		self.linear = torch.nn.Linear(1, 1) #输入和输出的维度（特征数）
		#构造一个对象，来自nn.Linear类：包含了权重和偏重
	
	def forward(self, x): #覆盖掉父类函数
		y_pred = self.linear(x) #对象后（）—— 实现了一个可调用(callable)对象
		#用线性运算块将x算出yhat
		return y_pred
#PyTorch 的 autograd 自动求导系统根据 `loss` 的计算图来算梯度
model = LinearModel() #创建一个可调用实例
```

#### Training Cycle
1. 算 $\hat y$
2. 算loss
3. backward
4. 更新
```python
for epoch in range(100):
	y_pred = model(x_data)
	loss = criterion(y_pred, y_data) #loss
	print(epoch, loss) #自动调用loss对象中__str__函数
	
	optimizer.zero_grad()
	loss.backward()
	optimizer.step()
```
