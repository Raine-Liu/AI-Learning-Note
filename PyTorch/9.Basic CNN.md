#### Convolutional Neural Network
**Feature Extraction**：
	Convolution（卷积）: 保留空间结构，且保持张量，C、M、H都可改变
	Subsampling（下采样）：通道数不变，改变宽和高，减少数据量
最终变为10维向量（一阶张量）
**Classification**

先提取特征，转化为向量，再通过全连接网络分类

#### Convolution
RGB通道图像：
	每一个格子一个颜色值——栅格图像
矢量图：通过数学公式储存（储存的是描述），可无限放大

Input Channel:R G B
取一个图像块(Patch)(3\*H'\*W')进行卷积，遍历图像
Output Channel:
输出包含了原图像块的所有信息

##### 3 Input Channel
每个通道配一个核，将结果相加，即为一次卷积运算

3\*3的卷积左右上下各减1
The shape of kernel tensor is (n, 3, 3)
The shape of output tensor is (1, 3, 3)

##### Convolution Layer
定义卷积层：输出通道数、输入通道数、卷积核大小
![9.Basic CNN-1783602493359.webp](images/9.Basic%20CNN-1783602493359.webp)
```python
import torch
in_channels, out_channels = 5,10
width, height = 100, 100
kernel_size = 3
batch_size = 1

input = torch.randn(batch_size, in_channels, width, height) #从正态分布进行采样的随机数
conv_layer = torch.nn.Conv2d(in_channels, out_channels, kernel_size = kernel_size) #卷积核尺寸可以给整数也可以给元组
output = conv_layer(input)

print(input.shape) #torch.Size([1, 5, 100, 100])
print(output.shape) #torch.Size([1, 10, 98, 98])
print(conv_layer.weight.shape) #torch.Size([10, 5, 3, 3])
```

**Padding**：
通过补0，在不改变卷积核的情况下增加输出维数
![9.Basic CNN-1783603283686.webp](images/9.Basic%20CNN-1783603283686.webp)
```python
import torch
input = [3, 4, 6, 5, 7, 2, 4, 6, 8, 2, 1, 6, 7, 8, 4, 9, 7, 4, 6, 2, 3, 7, 5, 4, 1]
input = torch.Tensor(input).view(1, 1, 5, 5)

conv_layer = torch.nn.Conv2d(1, 1, kernel_size=3, padding = 1, bias = False)

kernel = torch.Tensor([1, 2, 3, 4, 5, 6, 7, 8, 9]).view(1, 1, 3, 3)
conv_layer.weight.data = kernel.data

output = conv_layer(input)
print(output)
```

**stride**:
步长，规定每次中心移动几格，在不改变卷积核的情况下减少输出维数
```python
conv_layer = torch.nn.Conv2d(1, 1, kernel_size=3, stride = 1, bias = False)
```
