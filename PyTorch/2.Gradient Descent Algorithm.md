当有多个权重时，穷举搜索非常困难
**分治**：分块访问最小值，再细化——找到的是局部最优（凸函数可以用分治法找到最优点）
**优化问题**：找使目标函数最小的权重取值

#### Gradient Descent Algorithm
**Gradient**:$\frac{\partial cost}{\partial \omega}$函数上升的方向
**Update**：$\omega = \omega - \alpha \frac{\partial cost}{\partial \omega}$每次向下降最快的方向更新（$\alpha$学习率）
贪心算法，在非凸函数中只能找到局部最优点
全局最优点：没有一个局部最优点比它还小
实际应用中，损失函数的局部最优点很少，但会出现鞍点（g=0），陷入鞍点无法运动
$\frac{\partial cost(\omega)}{\partial \omega} = \frac{1}{N}\sum\limits_{i=1}^N 2x_n·(x_n·\omega - y_n)$
update：$\omega = \omega - \alpha\frac{1}{N}\sum\limits_{i=1}^N 2x_n·(x_n·\omega - y_n)$

```python
import numpy as np
import matplotlib.pyplot as plt

x_data = [1.0, 2.0, 3.0]
y_data = [2.0, 4.0, 6.0] #准备训练集

w = 1.0

def forward(x):
	return x * w #前馈计算

def cost(xs, ys):
	cost = 0
	for x, y in zip(xs, ys): #用zip拼装
		y_pred = forward(x)
		cost += (y_pred - y) ** 2
	return cost / len(xs)

def gradient(xs, ys):
	grad = 0
	for x, y in zip(xs, ys):
		grad += 2 * x * (x * w - y)
	return grad / len(xs)

# 准备列表保存训练过程
epoch_list = []
loss_list = []
w_list = []

print('Predict (before training)', 4, forward(4))

for epoch in range(100): #进行100轮训练
	cost_val = cost(x_data, y_data)
	grad_val = gradient(x_data, y_data)
	w -= 0.01 * grad_val

	print('Epoch:', epoch, 'w=', w, 'loss', cost_val)

	# 每一轮都保存一次
	epoch_list.append(epoch)
	loss_list.append(cost_val)
	w_list.append(w)

print('Predict(after training)', 4, forward(4))

# 画 loss 曲线
plt.plot(epoch_list, loss_list)
plt.ylabel('Loss')
plt.xlabel('Epoch')
plt.title('Loss during training')
plt.show()
```

最终要收敛
如果函数有很多波动，可以据加权均值使其更平滑$C'_i = \beta C_i + (1 - \beta)C'_{i-1}$
如果函数发散，说明训练失败了——可能是学习率太大了

#### Stochastic Gradient Descent

$\omega = \omega - \alpha \frac{\partial loss}{\partial \omega}$随机选一个样本的损失函数
cost(w)可能遇到鞍点，1个样本的随机噪声可能使我们越过鞍点
$\frac{\partial loss_n}{\partial \omega} =2x_n·(x_n·\omega - y_n)$
```python
import matplotlib.pyplot as plt

x_data = [1.0, 2.0, 3.0]
y_data = [2.0, 4.0, 6.0]

w = 1.0
lr = 0.01

def forward(x):
    return x * w

def loss(x, y):
    y_pred = forward(x)
    return (y_pred - y) ** 2

def gradient(x, y):
    return 2 * x * (x * w - y)

def total_loss():
    loss_sum = 0
    for x, y in zip(x_data, y_data):
        loss_sum += loss(x, y)
    return loss_sum / len(x_data)#用平均loss衡量拟合效果

epoch_list = []
loss_list = []
w_list = []

print('Predict before training:', 4, forward(4))

for epoch in range(100):
    for x, y in zip(x_data, y_data):
        grad = gradient(x, y)
        w = w - lr * grad

    avg_loss = total_loss()

    epoch_list.append(epoch)
    loss_list.append(avg_loss)
    w_list.append(w)

    print("progress:", epoch, "w=", w, "loss=", avg_loss)

print('Predict after training:', 4, forward(4))

plt.plot(epoch_list, loss_list)
plt.xlabel('Epoch')
plt.ylabel('Loss')
plt.title('Training Loss')
plt.show()
```
不能并行，时间复杂度高

| 性能    | 低    | 高      |
| 时间复杂度 | 低    | 高      |

**Mini-Batch**：批量随机梯度下降，将若干个样本分为一组，每次用一组样本更新梯度
```python
import numpy as np
import matplotlib.pyplot as plt

x_data = [1.0, 2.0, 3.0]
y_data = [2.0, 4.0, 6.0] # 准备训练集

w = 1.0
lr = 0.01
batch_size = 2

def forward(x):
	return x * w # 前馈计算

def cost(xs, ys):
	cost = 0
	for x, y in zip(xs, ys):
		y_pred = forward(x)
		cost += (y_pred - y) ** 2
	return cost / len(xs)

def gradient(xs, ys):
	grad = 0
	for x, y in zip(xs, ys):
		grad += 2 * x * (x * w - y)
	return grad / len(xs)

epoch_list = []
loss_list = []
w_list = []

print('Predict (before training)', 4, forward(4))

for epoch in range(100): # 进行100轮训练

	# mini-batch：每次取 batch_size 个样本
	for start in range(0, len(x_data), batch_size):
		end = start + batch_size

		x_batch = x_data[start:end]
		y_batch = y_data[start:end]

		grad_val = gradient(x_batch, y_batch)
		w -= lr * grad_val

	# 每个 epoch 结束后，用全部数据算一次 loss，判断整体训练情况
	cost_val = cost(x_data, y_data)

	print('Epoch:', epoch, 'w=', w, 'loss', cost_val)

	epoch_list.append(epoch)
	loss_list.append(cost_val)
	w_list.append(w)

print('Predict(after training)', 4, forward(4))

plt.plot(epoch_list, loss_list)
plt.ylabel('Loss')
plt.xlabel('Epoch')
plt.title('Loss during training')
plt.show()
```
