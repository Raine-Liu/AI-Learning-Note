#### Multiple Dimension Logistic Regression Model
$$
\sum\limits_{n=1}^8 x^{(i)}_{n}\omega_{n}= \begin{bmatrix}
x^{(i)}_{1}\dots x^{(i)}_{8}
\end{bmatrix}\begin{bmatrix}
w_{1}\\.\\.\\.\\w_{8}
\end{bmatrix}
$$
$$
\hat{y}^{(i)}=\sigma(\begin{bmatrix}
x^{(i)}_{1}\dots x^{(i)}_{8}
\end{bmatrix}\begin{bmatrix}
w_{1}\\.\\.\\.\\w_{8}
\end{bmatrix}+b)=\sigma(z^{(i)})
$$

#### Diabetes Prediction
Example：8 -> 6 -> 4 ->1
1. prepare dataset
```python
import numpy as np
xy = np.loadtxt('diabetes.csv.gz', delimiter=',', dtype = np.float32) 
#读训练数据：文件名，分隔符，指定数据类型（n卡GPU中只支持32位float)
x_data = torch.from_numpy(xy[:,:-1]) #所有行；从第一列开始，第8列（最后一列）不要
y_data = torch.from_numpy(xy[:,[-1])  #所有行；第八列，加[]变成矩阵
#从numpy的数值中创建出两个tensor
```
2. Define Model
```python
import torch

class Model(torch.nn.Module):
	def __init__(self):
		super(Model, self).__init__()
		self.linear1 = torch.nn.Linear(8, 6)
		self.linear2 = torch.nn.Linear(6, 4)
		self.linear3 = torch.nn.Linear(4, 1)
		self.sigmiod = torch.nn.Sigmoid() #此处的sigmoid是一个模块，没有参数(可以换成其他激活函数）
	#建立模型
	
	def forward(self, x):
		x = self.sigmoid(self.linear1(x))
		x = self.sigmoid(self.linear2(x))
		x = self.sigmoid(self.linear3(x)) #一串：用一个x即可
		return x
model = Model()
```
3. Construct Loss and Optimizer
```python
criterion = torch.nn.BCELoss(size_average=True)
optimizer = torch.optim.SGD(model.parameters(), lr=0.1)
```
4. Training Cycle
```python
for epoch in range(100):
	#Forward
	y_pred = model(x_data)
	loss = criterion(y_pred, y_data)
	print(epoch, loss.item())
	 
	#Backward
	optimizer.zero_grad()
	loss.backward()
	
	#Update
	optimizer.step()
```
