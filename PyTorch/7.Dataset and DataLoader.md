**Definition**:
Epoch: One forward pass and one backward pass of all the training examples.
Batch-Size: The number of training examples in one forward backward pass.
Iteration: Number of passes, each pass using [batch size] number of examples. //有多少个batch

```python
import torch
from torch.utils.data import Dataset #抽象类，只能由子类继承
from torch.utils.data import DataLoader #可以实例化

class DiabetesDataset(Dataset): #继承自Dataset
	def __init__(self):
		pass
	
	def  __getitem__(self, index) #使对象能支持下标操作
		pass
	
	def __len__(self): #使对象能由len给出数据条数
		pass
	
dataset = DiabetesDataset()
train_loader = DataLoader(dataset = dataset, batch_size = 32, shuffle = True, num_workers = 2) #传入数据集、batch大小、是否打乱、需要几个并行进程
```
构造数据集：
法一：initial时加载入所有数据，用下标选择。适用于少量数据
法二：大量数据，initial时定义一个列表，存每一条数据的文件名，使用时逐条加载
