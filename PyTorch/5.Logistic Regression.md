#### Logistic Regression Model

线性运算后，加入logistic作变换
![Logistic Regression-1783501719223.webp](images/Logistic%20Regression-1783501719223.webp)

loss fiction for linear regression ：$loss=(\hat{y}-y)^2$ 表示估计值与实际值在数轴上的距离，是一个数值
- loss fiction for  binary classification ：要表示两分布间的差异 （KL散度、cross-entropy...)
	cross-entropy:$P_{D_{1}}(x),P_{D_{2}}(x)$ : $\sum_{i}P_{D_{1}}(x_{i})\ln P_{D_{2}}(x_{i})$  越大越接近
	$loss =- (y\log \hat{y} + (1-y)\log (1-\hat{y}))$  (BCE损失）越小越好
		$y=1,\hat{y}$ 越接近 1 越好
		$y= 0,\hat{y}$ 越接近 0 越好
- mini-batch loss fiction for  binary classification (对数回归加最大似然）
	 $loss =- \frac{1}{N}\sum(y\log \hat{y} + (1-y)\log (1-\hat{y}))$

import torch.nn.functional as F

class LogisticRegressionModel(torch.nn.Module):
	def __init__(self): 
		super (LogisticRegressionModel, self).__init__() 
		self.linear = torch.nn.Linear(1, 1) 
	#sigmiod不需要参数，直接调用即可
	def forward(self, x): 
		y_pred = F.sigmoid(self.linear(x))
		return y_pred

criterion = torch.nn.BCELoss(size_average=False) #二分类的交叉熵
#是否求平均影响学习率的设置
